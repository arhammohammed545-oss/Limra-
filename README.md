# Limra — 3D-inspired real estate website

A responsive, premium real-estate landing page built as a static site for Vercel.

## Run locally
Open `index.html` in a browser, or run a static server:
`npx serve .`

## Deploy
Import this repository into Vercel. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.

## Notes
- Property listings, prices and locations are illustrative demo content, not live listings.
- Enquiry form is UI-only; connect a form endpoint/CRM before accepting customer leads.
- Images and fonts are loaded from Unsplash and Google Fonts.
