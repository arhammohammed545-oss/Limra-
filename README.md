# Limra — Real Estate Landing Page

A premium, dark real-estate landing page built with Next.js, React, VengeanceUI's motion-led design approach, and a Three.js-powered villa hero (React Three Fiber).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Notes

- This is a marketing landing page, not a SaaS dashboard.
- Property names, locations and prices are sample content and should be replaced with verified listings.
- The contact CTA currently opens an email draft; connect a CRM or enquiry endpoint before collecting leads.
